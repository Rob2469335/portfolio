## 🔍 Independent Credential Verification

Employers and recruiters do not have to rely on résumé claims. Every credential listed in this portfolio includes:
1. **Direct Verification URL**: Links directly to Coursera's official cryptographic certificate verification page (`https://www.coursera.org/account/accomplishments/verify/<ID>` or `/specialization/certificate/<ID>`).
2. **Public Share URL**: Official Coursera share link where available.
3. **Verified Recipient Name**: Confirms credential awarded to **Robert locust**.
4. **Issuing Institution & Completion Date**: Authenticated by Vanderbilt University, Google, IBM, NVIDIA, Meta, AWS, and University of Colorado System.

## 🚀 How to Run the Portfolio Locally

The portfolio is built as a zero-dependency, ultra-fast static website.

### Option 1: Direct File Open
Simply double-click `index.html` or open it in any modern browser (Chrome, Edge, Firefox, Safari).

### Option 2: Python HTTP Server
Run from the project folder:
```bash
python -m http.server 8000
```
Then navigate to: `http://localhost:8000`

## 🌐 Public Hosting & Deployment Recommendation

The portfolio is self-contained and pre-configured for free static hosting on **GitHub Pages**:

### Recommended Deployment via GitHub Pages:
1. Create a repository on your GitHub account (`https://github.com/Rob2469335/credentials-portfolio` or `<username>.github.io`).
2. Add and commit `index.html`, `styles.css`, `app.js`, `credentials_master.json`, `credentials_master.csv`, and documentation.
3. In GitHub Repository Settings → **Pages** → Source: **Deploy from a branch** → Branch: `main` / `root`.
4. Your portfolio will immediately be available at:
   `https://Rob2469335.github.io/credentials-portfolio/`

*(Per project guidelines, no git push or external deployment has been executed without your explicit authorization).*
